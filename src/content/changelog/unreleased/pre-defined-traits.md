Building a creature just got faster. The Traits section now has an **Insert preset** button that opens a searchable library of common D&D traits — Pack Tactics, Magic Resistance, Legendary Resistance, Spellcasting, and many more — so you can drop them in with one click instead of typing them out.

- Added a searchable pre-defined trait library to the editor's Traits section
- Presets use live markup, so damage, to-hit, and save values compute from the creature's stats automatically
- New `{@mon}` tag inserts the creature's name and tracks renames live
