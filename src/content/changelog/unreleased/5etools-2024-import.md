Importing monsters from 5eTools is more forgiving now. Newer 2024-era bestiary files describe some speeds and resistances in a format Monsterbrew didn't recognize, and one unrecognized field was enough to reject the whole creature. Those monsters now import cleanly.

- Hovering flyers (like the Air Elemental) import with the right fly speed and the hover flag set
- Conditional speeds, such as a climb speed that only applies in a certain form, no longer block the import
- Special resistance notes no longer block the import
